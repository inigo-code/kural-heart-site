Add to F-Droid
  1. Install F-Droid (or Neo Store, Droid-ify) if you don't have it.
  2. Tap Add to F-Droid above and confirm.
  3. Search for Kural Heart in F-Droid and install it.

If the button does nothing, open F-Droid, go to Settings, Repositories, +, and paste the address below.
